# Victor Barbosa da Cruz

Analista de dados desde 2021, em São Paulo. Construo bases de dados, dashboards e automações para a área comercial. No tempo livre, uso IA (Claude Code) para tirar ideias do papel em dias: robôs de coleta, validações de mercado com dados públicos e sites.

Estudante de Análise de Dados na Unifecaf.

## Projetos

| Projeto | O que é | Feito com |
|---|---|---|
| [Agente de roteiro com checagem de fatos](https://github.com/VicYone/skill-roteiro-checagem-fatos) | Skill do Claude Code que escreve roteiros sobre casos reais e só libera o texto depois de duas revisões, uma delas por um subagente revisor independente | Claude Code, subagentes |
| [Monitor de editais de concurso](https://github.com/VicYone/monitor-editais-concursos) | Robô semanal que lê os PDFs dos editais e acha os que exigem exame toxicológico. Cobertura de 537 para 985 concursos | R, web scraping, pdftools |
| [Validação de ideia com dados públicos](https://github.com/VicYone/validacao-fila-pagamentos-prefeituras) | 22 prefeituras e 86 mil pagamentos raspados em um dia para testar uma ideia de produto antes de construí-la | Node.js, APIs públicas |
| [Gerador de landing pages](https://github.com/VicYone/gerador-landing-pages) | Transforma um JSON numa página pronta, com validador de contraste, links e desempenho. Mais de 150 páginas geradas | Node.js, HTML/CSS |
| [Nireceitas](https://github.com/VicYone/nireceitas) | Site de receitas feito do zero em um dia, com busca e dados estruturados para o Google | HTML, CSS, JavaScript |
